# gestion_immo


pour configurer git github :   

git config --global user.name "votre nom d'utilisateur git"
git config --global user.email "votre email git "


cd : pour se deplacer

git init : pour initialiser

git add . : pour ajouter mis en jour

git commit -m "messagee"   : pour valider update

git push : pour heberger sur le serveur github ou gitlab
